# janus

Released-edge integration shape:

- registration, heartbeat, doorbell, and upstream replacement;
- finite files and browser publication;
- `X-Sendfile`;
- directory browse;
- Hub transport;
- cache behavior;
- registration-scoped access observation;
- deregistration on clean shutdown.

This fixture runs through a Janus-enabled Caddy binary built from the published
release tag; a control-plane stub does not satisfy it.
